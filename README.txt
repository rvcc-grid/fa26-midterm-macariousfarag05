HOW TO USE:
1. Accept your instructor's GitHub Classroom invitation first.
2. Clone YOUR assigned repository in VS Code.
3. Copy index.html, css/style.css, and the five img files into the corresponding locations in your assigned repo. If your instructor expects specific starter markup or behavior, merge the content/styles rather than deleting required elements.
4. Use Live Server to preview and check mobile size in Chrome Developer Tools.
5. Replace hello@example.com with an address you want to use, or keep it clearly fictional for the fictional agency.
6. In VS Code Source Control: stage changes, commit "Build responsive Northstar Studio midterm website", and push/sync.
7. Open the published GitHub Pages URL and submit that actual URL. Pushing this zip on its own is NOT the same as publishing to the assigned site.

All portfolio projects and testimonials are fictional. Illustrations are original assets made for this example.
